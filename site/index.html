02 Features

Keep every agent in its lane.

Runs can each get their own branch. Every finished diff lands in one inbox.

Say what you want built

Hit Ctrl+Shift+O and tell Viby what you need. Your signed-in CLI, or your own local model, turns it into a plan without touching disk, then launches each agent on its own git branch. Low-risk steps run straight away by default while risky ones wait for Go — or switch between Ask for everything and Never ask in Settings.

Let Viby use the screen, if you allow it

Turn on Computer use in Settings, then choose for VibeForge's window, the browser in Code and the desktop whether Viby may see it, click and scroll in it, or type in it. It stays off until you turn it on, and Viby can't change it. You choose how often it asks first; by default it types only what you said, and anything the screen tells it to type waits for your Go.

Talk hands-free with Viby

Press Ctrl+Shift+L from any view to start a local voice call. Viby knows which terminal you're viewing and answers aloud with Piper. Talk over it to cut in (with headphones, or PipeWire's echo cancelling); destructive actions still wait for you to say "go".

Run on your own models, when you want to

Turn on Local AI in Settings and connect llama.cpp, Ollama, LM Studio, or a machine on your home network or Tailscale. OpenCode, Claude Code or Codex then codes on that model, and Viby can plan with it too. VibeForge can start and stop the server for you, too: llama.cpp over a folder of models, Ollama, LM Studio, or a launch script of your own. The Cloud / Local button at the foot of the rail switches back whenever you like. It stays off until you turn it on, and your cloud CLIs' own settings are never touched.

Let one CLI ask another

Every terminal has vibeforge on its PATH. Claude Code can ping Grok for a second opinion with vibeforge tell, or delegate a subtask to a separate git branch with vibeforge task. Turn caps stop runaway loops.

An Android widget, if you want one

A home-screen bar that shows what your CLIs and Viby are doing on your computer, with Go, Cancel and quick replies, and opens the phone page where you tap. It needs VibeForge running on your computer, your phone able to reach its phone page (for example over Tailscale), and Android 9 or newer.

It isn't in the Play Store: you download the APK, allow your browser to install it, and pair it once by scanning the QR code in Settings → Phone (or typing its address and code). Each release lists its SHA-256 beside it.

Review the changes file by file

The moment a run finishes, VibeForge saves its transcript and full git diff, so later edits stay out of it, and Continue reopens that exact CLI session. A task's or Viby's copy opens as a list of files you can fold, mark Viewed and leave notes on, and Apply brings in only the files you tick; the rest wait in the copy. A run that worked in your own folder can put its files back as they were before it, from a list you read first, with Undo.

Pick up where your CLIs left off

If VibeForge quits, crashes or restarts while Claude Code is working in a pane, that pane offers Continue its session when VibeForge is back, and a notice offers Continue all. VibeForge reads which session each CLI is in from the CLI's own log (Claude Code, Codex, Grok Build and Copilot), so two Claude Codes in one folder each get their own session back, started with the options you gave them.

Run agents on cron or fixed intervals right from the tray. Missed slots get logged instead of piling up after sleep. Each run ends by itself when the CLI's turn is done and says how it went: finished, stuck on a question, timed out or failed.

// Under the hood

How a run works.

Real CLI processes running in real terminals, captured straight to disk.

  1. 01

    Prompt handed straight to the CLI

    VibeForge bundles the agent's instructions and memory, then passes them via the CLI's native prompt flag.

  2. 02

    Runs in a headless PTY

    Each process runs in its workspace, or in its own git worktree, and keeps running when you close to the tray.

  3. 03

    Snapshot saved on exit

    When a run ends, its transcript and full git diff are written straight to disk.

  4. 04

    Pick up the exact session

    Hit Continue to resume the CLI's native session ID and keep typing where it stopped, also after VibeForge restarts.
