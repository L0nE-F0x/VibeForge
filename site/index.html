One window for the whole crew.

Vibe coding on Omarchy already works: the CLIs are installed and signed in. What was missing is one window that remembers who does the work, where they may work, when work starts, and what to review when it ends.

VibeForge is that window. It never calls a model API and never holds a key. Every engine is a CLI you're already signed in to; VibeForge gives them a home, a schedule and a memory.

No accounts. No telemetry. Everything on disk is plain YAML and Markdown in ~/.config/vibeforge, so you can change it all from Neovim.

See it in action

The desk on a real day: the review inbox, tiled terminals, a board of work.

A crew, not a chat box.

Agents are teammates with a job. Routines and tasks decide when work starts.

Teammates that outlive the engine

Each agent keeps a brief, a memory file, installed skills and the folders it may touch. Switch it from Claude Code to Codex to Grok and it's still the same teammate.

Routines that respect your time

Cron or intervals, read back in plain words. Each fire is a fresh run. They only run while VibeForge is open, and missed slots are shown, never replayed.

Tasks that wait for you

Writing or assigning a task never starts anything. Execute does. When the process ends, the task lands in Review with its diff.

Tiled like the rest of your desktop.

Real terminals, arranged the Hyprland way, and a record of everything they did.

Real terminals, not a chat skin

WebGL xterm, split and dragged into place. Plain Ctrl V reaches the program, so pasting screenshots into Claude Code works like in ghostty.

Review everything they touched

Every run keeps its final screen, a transcript, the exact prompt and the git diff since it began. Continue reopens the very same session.

Knows what's on your PATH

Finds your CLIs through your login shell (mise, ~/.local/bin, all of it). Prompts go in as one argument, or get pasted once the CLI has settled.

Yours, and nobody else's.

No sign-up, no cloud, no keys. It keeps itself current and speaks your language.

Private by construction

No accounts, no API keys, no telemetry. VibeForge only ever asks GitHub for the newest release number, and you can turn that off.

Updates itself, in plain sight

When a release is out, Help gets a dot. Update shows the notes, runs the installer in a terminal you can watch, and restarts.

Seven languages

English, Deutsch, Español, Français, Português, 日本語 and 简体中文, following your system language unless you pick one.

It wears your theme.

Chrome from colors.toml, terminals from your ghostty palette, restyled the moment you switch. Pick one, or press T, and this page follows.

What happens when you hit Send.

No magic, no parsing a TUI into cards. A process, a terminal, and a record.

  1. 01

    One argument, intact

    The brief, memory, skills and your prompt reach the CLI as a single argument. Nothing is typed into a TUI line by line.

  2. 02

    A real terminal

    It runs in the agent's allowed folder. A headless mirror keeps every screen, so switching views never loses a line.

  3. 03

    A record when it ends

    Final screen, transcript and a git snapshot land in the run folder. Stop hangs up the process group, like closing a window.

  4. 04

    Pick it back up

    Continue reopens the exact session. Follow-ups are pasted into the live CLI and submitted, even multi-line ones.

Install VibeForge

One line on Omarchy, or any Arch + Hyprland setup. Then Super Space and type VibeForge.

Read the README

One line

Clones the newest release into ~/.local/share/vibeforge-app, builds it, and adds the vibeforge command and a launcher entry.

$ curl -fsSL https://vibe-forge.net/install | bash

Needs git, base-devel and python, and Node 20+ (mise use -g node@lts on Omarchy). Add --uninstall to remove the launcher; your data stays.

Build it yourself

MIT licensed, and hacking on it is the point. Clone, install, and run it with hot reload.

git clone https://github.com/L0nE-F0x/VibeForge.git
cd VibeForge
npm install
npm start            # Vite + Electron, hot reload
npm run build && ./scripts/vibeforge
