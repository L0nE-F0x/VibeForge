02 Features

A crew, not a chat box.

The CLIs are already installed and signed in. VibeForge remembers who does the work, where they may work, when work starts, and what to review when it ends.

Teammates that outlive the engine

Each agent keeps a brief, a memory file, installed skills and the folders it may touch. Switch it from Claude Code to Codex to Grok and it's still the same teammate.

Cron or intervals, read back in plain words. They only run while VibeForge is open; missed slots are shown, never replayed.

— Under the hood

What happens when you hit Send.

No magic, no parsing a TUI into cards. A process, a terminal, and a record.

  1. 01

    One argument, intact

    The brief, memory, skills and your prompt reach the CLI as a single argument. Nothing is typed into a TUI line by line.

  2. 02

    A real terminal

    It runs in the agent's allowed folder. A headless mirror keeps every screen, so switching views never loses a line.

  3. 03

    A record when it ends

    Final screen, transcript and a git snapshot land in the run folder. Stop hangs up the process group, like closing a window.

  4. 04

    Pick it back up

    Continue reopens the exact session. Follow-ups are pasted into the live CLI and submitted, even multi-line ones.
